# Cozy Pottery — смарт-линк

Одна ссылка на обе платформы. Определяет устройство и перебрасывает в нужный магазин,
подставляя метки кампании, чтобы переходы было видно в консолях.

**Ссылка для размещения:**

```
https://pepepriv.github.io/cozypottery/?c=pupirka
```

| Кто открыл | Куда | Метка |
|---|---|---|
| Android | Google Play | `utm_source` / `utm_medium` / `utm_campaign` в параметре `referrer` |
| iPhone, iPad | App Store | `ct=` |
| Десктоп | страница с двумя кнопками | — |

## Новая кампания

Метки живут в словаре `CAMPAIGNS` внутри `index.html` — не пиши их руками в постах,
иначе в отчётах один канал расползётся на несколько написаний. Новый канал — одна строка:

```js
youtube_devlog: { source: 'youtube', medium: 'social', campaign: 'devlog_1' }
```

Дальше ссылка `?c=youtube_devlog`. Неизвестный ключ не ломает страницу: она уводит
в магазин с меткой по имени ключа.

## Где смотреть

- **Android** — Play Console → Рост → Эффективность магазина → Отчёты о привлечении. Задержка 1–3 дня.
- **iOS** — App Store Connect → App Analytics → Acquisition, разбивка Campaigns. Раз в сутки.
  Считаются только те, кто не отключил обмен аналитикой, поэтому числа занижены —
  каналы сравнивать между собой можно, с отчётом о продажах сводить нельзя.
